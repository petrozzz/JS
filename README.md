# JS учебные проекты

Небольшой набор учебных работ по JavaScript, HTML и CSS.

## Структура

- `index.html` — главная страница‑каталог с ссылками на все проекты (для локального запуска и GitHub Pages).
- `HW1` — базовое домашнее задание.
- `HW5 BookShop` — макет интернет‑магазина книг.
- `HW5 Forum Messanger` — прототип форума/мессенджера.
- `HW5 KassirRU` — страница в стиле билетного сервиса.
- `HW5 Test` — тест/опрос с формой.
- `HW5 TextStyle` — работа со стилями текста.
- `HW5 WhoIsAbsentToday` — мини‑приложение для учёта присутствия.
- `EX FormRegist` — эксперимент с формой регистрации.
- `EX PixelPainter` — простой «пиксельный» редактор.
- `EX GuitarFretCards` — карточки для запоминания нот на грифе (режимы «нота -> лад» и «лад -> нота», статистика).

## Как открыть локально

В PowerShell из корня репозитория:

```powershell
cd D:\project\learn\JS
start .\index.html
```

Откроется главная страница с удобными ссылками на все проекты.
