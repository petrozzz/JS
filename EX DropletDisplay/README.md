# Моделирование капельного дисплея

Веб-симуляция на HTML/CSS/JavaScript: **одна линия сопел** вверху сетки. Кадр строится **по строкам растра снизу вверх**: на строке `r` **все** активные столбцы вылетают **одновременно** (вся горизонтальная перемычка буквы **H** — в один такт, а не в первый вместе с низом ножек). Между строками задержка **Δτ**. Все капли с одной высоты `y₀`.

Сразу под соплами цепочки **сплющены** (малый разрыв между соседними по времени каплями). При падении разрыв растёт (**Δy ≈ g·Δτ·t̄**). **Полоса строба** задаёт область, где контраст выше — наглядно «окно», где букву проще различить.

## Как это устроено

1. **Матрица** 20×20 — растр текста.
2. **Кадр** — для `r = 19 … 0`: если в строке есть активные ячейки, все они получают один `τ = T₀ + k·Δτ`, затем `k++`. Сначала нижняя строка буквы, затем выше.
3. **Физика** — `y = y₀ + ½g(t−τ)²` после вылета; до `τ` капля в сопле и не рисуется.
4. После того как все капли кадра ушли вниз — **пауза**, затем следующий кадр.
5. **Строб** — яркость в горизонтальной полосе по центру.

## Запуск

Откройте `index.html` в браузере.

## Управление

| Элемент | Действие |
|--------|----------|
| Текст + «Обновить» / Enter | Новая строка в матрице |
| Скорость падения (g) | Множитель ускорения для **следующего** кадра |
| Шаг Δτ между строками | Интервал между соседними горизонтальными «срезами» буквы |
| Пауза между кадрами | После исчезновения капель до нового кадра |
| Остальное | Яркость вне зоны, высота зоны, строб, следы |

На холсте пунктир — область «логической» сетки буквы; тонкая линия на уровне **сопел**.

## Примечания

- Реальный дисплей подбирает Δτ, g и строб под геометрию — здесь упрощённая демонстрация.
- Слайдер **Δτ** действует на **следующий** кадр.
